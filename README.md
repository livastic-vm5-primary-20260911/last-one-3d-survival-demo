# LAST ONE — 3D Survival Arena (Public Playable Demo)

**Play the game:** https://livastic-vm5-primary-20260911.github.io/last-one-3d-survival-demo/

Desktop browser game using Three.js and Vite. One human player versus 15 AI opponents.

- Third-person movement: WASD / Shift
- Aim and shoot: Mouse / left-click
- Reload: R; collect supplies: E; pause: Escape
- Procedural 3D forest/ruins arena, three weapons, shrinking safe zone,
  shield/health/stamina, minimap, AI combat and win/loss loop.
- Generated mesh/material and synthesized audio; no ripped copyrighted game art.
- Playable offline after distributing the compiled static assets with any web server.
